# 简单网页小游戏

这是一个基于 HTML + CSS + JavaScript 的简单网页小游戏，玩家在 30 秒内尽可能多地点击屏幕中的目标，获得更高分数。

## 功能说明

- 目标会随机出现在游戏区域中
- 点击目标即可加分
- 右上角显示剩余时间和当前分数
- 30 秒后游戏结束
- 支持重新开始

## 运行方式

直接用浏览器打开以下文件：

- `test.html`

## 文件结构

- `test.html`：游戏页面和逻辑
- `README.md`：项目说明文档

## 说明

这是一个非常简单的前端练手项目，适合学习：

- HTML 结构
- CSS 样式
- JavaScript 事件绑定
- DOM 操作
- 游戏循环逻辑

## 预览

打开 `test.html` 后即可体验游戏。
